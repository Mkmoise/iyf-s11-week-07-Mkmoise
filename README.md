## Project Description

This project demonstrates JavaScript best practices through several mini-projects and exercises. It includes a persistent To-Do List using localStorage, a Notes App, a Session Storage Form, and JavaScript exercises focused on state management, code organization, and testing.>

## Technologies Used

- HTML5
- CSS
- JavaScript (ES6)
- Local Storage API
- Session Storage API
- Git
- GitHub
- GitHub Pages


## Features

- Persistent To-Do List using localStorage
- Add, complete, delete, and filter tasks
- Notes App with saved notes
- Contact Form with sessionStorage auto-save
- Modular JavaScript structure
- Lesson 13 and Lesson 14 practice exercises
- Basic unit testing examples

## Lessons Learned

During this project I learned how to:

- Use localStorage to persist application data.
- Use sessionStorage to temporarily save form inputs.
- Organize JavaScript into multiple files.
- Manage application state.
- Write cleaner and more maintainable JavaScript.
- Create reusable helper functions.
- Work with Git and GitHub more confidently.


## Challenges Faced

Some of the challenges I encountered included:

- Resolving Git merge conflicts.
- Synchronizing local and remote repositories.
- Organizing code into separate JavaScript modules.
- Fixing GitHub Pages deployment issues.
- Managing persistent application state using localStorage.

These challenges were solved by using Git commands correctly, restructuring the project, and testing each feature step by step.
